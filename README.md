## 归档内容

- `training/records/`：实际训练配置、训练日志、速度基准和数据选择统计。
- `training/tools/`：本次使用的数据准备、特征提取和训练辅助脚本。
- `training/environment/`：当时的依赖清单与版本约束。
- `production/`：清晰度研究、局部修复、历次版本脚本、参数、测量及说明。
- `MANIFEST.json`、`SHA256SUMS.txt`：归档文件大小、来源说明及 SHA-256。
- `PACKAGING_AUDIT.json`：本次文件范围检查和 WAV 头信息。

## 训练记录与限制

实际最终检查点为 G_60004（约 60k 步），本仓库不提供该文件。
训练配置为 batch size 1、44.1 kHz、单角色 ayane；最后一阶段基准约 0.611 秒/步。
选择统计记录 2,229 条、约 60.2 分钟有声素材、加权训练列表 2,737 行。
建库历史脚本的验证集也被包含在训练 items 中，故不能把相关验证当作严格独立的泛化评估。

这是成果与过程归档，并非完整可执行的训练发行包。运行时还需要自行准备上游
so-vits-svc 工程、合法来源的素材、模型及环境。历史脚本保留当时的本地路径；部分旧版
中间音频已清理，路径与输出名称也可能已变动，不能保证直接重跑。旧说明中的
“最新”“待试听”等仅描述当时状态，当前成品以本 README 和 V14 音频为准。
